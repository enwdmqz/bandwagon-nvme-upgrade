## NVMe 到底比 SATA SSD 快在哪

快在并发小 IO 的处理能力和延迟上，这一点对 VPS 的影响比“顺序读写多少 MB/s”大得多。

原理不难理解：SATA 接口的 SSD 吞吐上限约 600 MB/s，命令队列只有一条；NVMe 走 PCIe 通道，Gen4 最高能到 7,000 MB/s，且每个 CPU 核心都有并行队列。而 VPS 上的真实负载——数据库读取、WordPress 页面拼装、Node.js 的文件系统调用——几乎全是海量的小块随机 IO。SATA 上这些请求要排队等前一个完成，NVMe 上它们可以同时处理。

以常见的 MySQL 基准测试为例，NVMe 的 P99 延迟大约只有 SATA 的十分之一。平均查询速度快一点你未必感觉得出来，但最慢的那批查询快一个数量级，高峰期的卡顿感会明显消失。数据库、电商下单这类场景受益最直接。

这次升级用的还是 NVMe RAID-10 阵列：条带化负责速度，镜像负责冗余。单盘 NVMe 坏一块数据就危险了，RAID-10 把磁盘故障导致数据丢失的风险压低了不少。对要放生产业务的人来说，这个冗余比跑分重要。

处理器同步换成 AMD EPYC 也有实际收益：多核性能更强（Docker、编译、高并发场景受益），L3 缓存更大（对随机读多的负载友好），能效优化带来的稳定性提升则是所有场景共享的。
